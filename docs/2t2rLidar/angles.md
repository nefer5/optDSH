# H/V视场角、方向与模型映射

采用N02总入口Skill的物理视场定义，来源见[入口](README.md)。本契约用于2t2rLidar领域，不把具体模型的轴、对象号和零位提升为平台常量。

## 1. 物理正方向

观察者位于设备端，面朝被测场景：

- 正前方与标称Tx/照明出射方向一致，记`+F`；标称视轴为`H=0, V=0`。
- **观察者自身右侧为+H，头顶上方为+V。** 场景中的目标在右侧/上方时，其H/V为正。
- 这是从设备看场景，不是从目标反看设备，也不是网页相机任意视角中的左右。

H、V是角度参数，F是前向分量标签。按“右、上、前”排序的分量组(H,V,F)不能直接当作Zemax右手XYZ：其基向量满足`h×v=−f`。Zemax世界/对象坐标仍保持原右手系；使用显式基向量投影，不用换标签代替坐标变换。这条说明补足N02原文未展开的手性边界。

## 2. 两个独立投影角

对**设备指向场景**的单位方向s，先在同一坐标系中计算`s_H=s·h`、`s_V=s·v`、`s_F=s·f`，再取：

```text
H_deg = atan2(s_H, s_F) × 180/π
V_deg = atan2(s_V, s_F) × 180/π
```

这不是极角/方位角定义；V也不是`atan2(s_V, sqrt(s_H²+s_F²))`形式的球坐标仰角。任务若需要其他参数化，另行命名并记录，不能直接混用数值。

在前向半空间`s_F>0`且|H|、|V|<90°时，对应方向可还原为：

```text
(s_H, s_V, s_F) = normalize(tan(H), tan(V), 1)
```

反向还原公式只适用于上述范围；侧向/后向目标须明确其分支，不从tan丢失的符号猜方向。计算库使用弧度，配置/报告角度明确写deg；不要用atan代替atan2隐去象限。

## 3. Rx入射方向

Tx传播方向通常由设备指向场景，可直接转换。Rx光线实际从场景回到设备，若读取到传播向量`d_in`，先用`s=−d_in`表示目标所在方向，再按相同公式计算H/V。

因此同一个右上方目标应在Tx视场和Rx视场都得到正H、正V。不要把Rx入射方向再不加说明地当作出射方向，也不要在控制映射和矢量转换中重复取反。

## 4. Zemax局部量到物理H/V

对象局部X/Y、Detector行列、TiltAboutX/Y正号及全局XYZ都不自动等于+H/+V。每个模型/通道在当次配置与inspect证据中记录：

- 标称视轴与坐标系；h/v/f基向量或等价且无歧义的转换。
- 控制对象身份/当前Comment、字段、参考对象、初值/零位和pickup关系。
- 控制值到物理H/V的系数与偏置；探测器局部轴到H/V的对应、符号和像素顺序。
- 已知场点的符号验证，至少能明确证明右侧为+H、上方为+V；中心点检查零位。显示相机旋转不改变这些物理定义。

工作台XY/XZ/YZ按钮只决定看世界XYZ的相机方向，不建立H/V的物理映射。Detector Rectangle的角度空间采样也有其自身参数化；须按对应API定义换算，不能把轴直接改名为H/V就当已一致。

## 5. 当前控制角映射（用户已确认）

N02的2026-08-05设计已记录以下换算；用户于2026-09-27明确确认当前2t2rLidar研究仍采用该关系，没有变化：

```text
H_deg = -2 × (scanner_h_deg - 45)
V_deg = -echo_v_deg
```

当前采用关系的正反例为：

| 实际控制值 | 物理角度 |
|---|---|
| scanner_h=45° | H=0° |
| scanner_h=40° | H=+10° |
| scanner_h=50° | H=−10° |
| echo_v=−2° | V=+2° |
| echo_v=+2° | V=−2° |

逆向为`scanner_h=45−H/2`、`echo_v=−V`。符号、45°零位及2倍系数必须作为配置保留；该式不是任意转镜/姿态/通道的普遍定律。

当前Rx Skill的真实配置接口已经支持：`actual=initial+delta`，再按`angle=actual*fov.scale+fov.offset_deg`换算。对应上例，H用scale=−2/offset=90，V用scale=−1/offset=0；**delta是控制量增量，不是物理视场角增量**，ΔH=−2Δscanner_h。包内示例只是待核对样例，不能据其数值宣布新模型符号已验证。

## 6. 平面探测器与显示

对于垂直标称视轴、平面轴与H/V轴已对齐的远场平面，距离R>0、光轴落点(x0,y0)已确认时，可采用N02的特例：

```text
H_edge = h_sign × atan2(x_edge-x0, R)
V_edge = v_sign × atan2(y_edge-y0, R)
```

h_sign/v_sign通常为±1，必须来自本模型核验。对旋转、倾斜、轴交换或其他几何关系，应先转换边界方向矢量，再按第2节计算，不只乘两个符号。

角域图默认H从左向右递增、V从下向上递增；数组可按`[V_index,H_index]`存储，但必须随数据保存H/V轴值与排序。数值表的行顺序可另行标示，不将屏幕行向下自动解释成物理+V。

将平面像素转换为角格时区分像素积分功率与W/sr等密度；非均匀角边界和重采样应核对能量账本，不能只改坐标轴标签。
