# 连接组件审查与本轮验收

日期：2026-10-18。范围：正式光学包、Web配置/进程管理与发行资源。由软件架构专家独立只读审查，修复后复核；未用架构扫描代替实际接口验证。

## 结论

连接代码属于正式可复用的`optdsh-optics` wheel，工作台只负责配置、启动和HTTP适配。公共入口`Bridge`与`capture.capture`复用版本校验、模型身份与跨进程实例锁；不引用临时脚本、旧项目或邻接源码。`legacy.py/legacy.ps1`是正式旧版适配器，PS文件随wheel分发，并保留PS5.1中文所需BOM；新版仍使用`connection.OpticStudio`与独立Python worker。

用户暂定2021及以前/2022起两类，默认新版；18/19共用旧适配器。分组是研发假设，具体能力另行验收。当前旧适配器只读；19与2025实测通过，18及其他具体年份未实测，不以大类名称冒充全版本验收。

## 发现与已修复问题

1. 首次配置崩溃后死PID锁会卡住保存：保存入口现在可恢复死PID锁，活进程仍拒绝；回归通过。
2. 旧PS桥曾只接受`zemax19`名称，误拒通用旧版目标：显式允许旧版组及18/19别名，实际执行包内PS到DLL加载边界的协议回归通过。
3. 仅比较构建年份不足以辨别同年不同构建：安装发现记录产品版本与完整API构建号，Python/PS连接后严格比较；元数据缺失或同年异构建明确拒绝。2025产品25.1与构建241210分别表达，不把构建日期当产品年份。

修复后限定范围复核无新增阻断项。Web保存只接收版本类标识，不接收任意命令或Python路径；运行中拒绝改版本，停止仅走认证的空闲退出，不关闭Zemax GUI。
