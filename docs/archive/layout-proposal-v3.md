## 坐标与观察方向

### 方案04补充：CW / CCW 45°（2026-09-26）

- 自由视图、固定视图工具栏均加入CW 45°与CCW 45°；含当前画面角度与复位入口。
- 设计解释：相机绕当前视线roll，顺逆时针以用户看到的画面为准；一次45°，8次回到原方向。不是绕某个世界轴orbit，更不是旋转镜片。
- 保持观察中心、观察侧和缩放；更新相机up方向与全局轴方向标。固定视图仍在所选投影面上，不能写死“屏幕右+Y/上+Z”而忽略roll。
- 切换XY/XZ/YZ预设或点击复位时roll归零；“反向观察”保留roll数值并按新观察侧解释CW/CCW。
- 实现验收：8次回环、CW后CCW抵消、保持target/zoom、反向后旋转语义、方向标同步；当前仅设计，未改产品代码。
- 新预览：artifacts/layout-proposal-v4/方案04-视角45度旋转.png / .svg。Figma仍未同步。

- 两个视口角落常驻全局XYZ方向标：X红、Y绿、Z蓝，随相机方向更新；明确区别于选中对象的局部轴。
- 场景中的全局原点轴可开关；其真实位置来自NSC全局框架，不将选中镜片中心冒充全局原点。原点在视野外时角落方向标仍可见。
- 固定视图保留XY/XZ/YZ等按钮，旁边增加反向观察：XY从±Z看，XZ从±Y看，YZ从±X看。
- 反向只改变相机，保持目标中心和缩放；上方向保持约定，屏幕右方向按相机变化更新标注。不是旋转/镜像光学模型。
- 当前预览示例是YZ从+X观察；“方向切换”按正反观察解释，若用户另指其他操作再调整。

## 列表与多选

- 类别使用低饱和底纹与细色条，文字同时显示对象类型；颜色语义与场景一致，不只依赖颜色辨认。
- 选中使用独立描边和选择标记，不能覆盖类别底纹。主对象为最后点击对象，属性栏明确标注多选数量。
- 拟议Ctrl/Cmd点击增减选择，Shift按当前列表范围选择；3D视图采用同一选择集合。
- 镜片列表底部“添加N个到对话”，可选对象菜单提供同一动作；不因选择变化自动改变草稿引用。

## 嵌入指令的对象引用

输入框采用结构化文档：普通文字段和不可拆开的object-reference节点交替存在。按钮在当前光标/选区处插入对象标签，保留其他文字。
例：`比较 [OBJ58] 和 [OBJ59] 的裁切关系`。标签支持删除、点击定位和悬停查看类型/版本；重复引用复用同一身份，不重复发送实体数据。

引用节点包含modelId、revision、objectId、displayLabel；显示标签不是身份。禁止把任意粘贴的“OBJ59”字符串自动升级为真实引用。
模型刷新后保留草稿文字，将引用标记为待核验；首版提交遇到过期引用拒绝，重新选择后由用户替换，不按对象号静默重绑定。
多模型/混合revision首版拒绝，后续另设计比较快照模式。

“添加到对话”只编辑草稿，“发送”才启动Agent。服务端逐项核验引用集合，并将其绑定到单次只读查询上下文。
现有单对象selection_context需扩展为有界多对象context：模型无需抄写长ID，由代码统一返回所引用对象及必要关联。比较对象的角色由指令或明确UI动作确定，不能默认对全部多选对象作所有两两比较。
标签中不塞完整网格/文件，发送稳定引用与必要摘要；原始坐标和属性通过工具按需查询。

## 实现与验收建议

- 用前端富文本编辑状态管理引用节点、光标、中文输入法、撤销及粘贴；不要简单拼innerHTML，也不要靠正则把文本伪装成对象引用。
- 可先实现受控的轻量编辑器；若输入复杂度增长，再评估成熟编辑器的inline atom能力，当前不引入新依赖。
- 验证多选→插入光标位置、删除单个引用、中文组合输入、撤销/重做、切换选择不污染草稿、旧revision拒绝及文本粘贴不伪造引用。
- 对象选择与输入过程不触发模型调用、布尔重算或宿主刷新；保持每分钟一次参数修改的性能基线。
