# M2.1 查看器升级建议

2026-09-26 用户反馈。状态：用户批准，M2.1首版已实现；具体支持范围及限制见 [操作说明](../guides/viewer-controls.md)。下文保留原方案，不能将其中未支持的特殊对象当作已完成。

## 目标

在现有只读桥接基础上，将原点检查器升级为可判断空间布局的近似实体查看器。先改善独立页面，再进行M3的DSH内嵌与对象提问提交。

当前前端使用Canvas手工投影，仅有光源/探测器/参考/其他四类。建议引入固定版本的Three.js渲染层；复用场景契约、鉴权、查询服务和MCP，不重写已验证数据链路。

## 用户提出的四项要求

1. 镜片用近似形状而非仅原点，允许非精准曲面。
2. 按对象分类配色，并在场景中清楚体现。
3. 类似3D软件的导航操作，可配置组合键和鼠标动作，如Shift+左键平移。
4. 支持2×2面板，包含三正交视图与空间视图。

## 实施顺序

### A. 渲染与导航基础

建立独立Scene、相机和控制器；默认左键拖动旋转、Shift+左键平移、滚轮缩放、单击选择、F聚焦。动作映射独立于渲染，提供设置、冲突检查、恢复默认，并按浏览器本地保存。输入框获得焦点时禁用字母快捷键，避免打字触发相机。

这些都是相机操作，不移动Zemax对象。快捷键改变后，界面帮助同步显示；保留轴向标识与重置视图入口。

### B. 近似形状与显示分类

补只读的尺寸采集和类型适配，将绘图形状与物理对象身份分离。优先覆盖Standard Lens、Even Asphere Lens、Rectangle、Rectangular Volume、Detector Rectangle，再逐步支持其他类型。

- 透镜：取已核验的口径与厚度，生成简化透镜/圆柱轮廓；不能把近似曲面当真实面形。
- 矩形面/滤光片/探测器：尺寸明确的薄板或平面。
- 方体/管道：在参数语义确认后显示盒体/框体。
- Compound Lens、Boolean Native：单独标记复合或布尔对象；不能把一种通用形状说成真实组合。优先经验证的包围表示，缺尺寸则用明确标注的示意形状或原点退化。

每个形状带representation与dimensionSource，显示“尺寸近似”“示意不按比例”或“暂不支持”。物体姿态继续来自GetMatrix；特别检查原点在前表面还是中心，避免把真实厚度错误地对称放置。

显示类别建议：透镜、反射面、滤光/分光、光源、探测器、结构件、参考、未知。Zemax几何类型与光学用途不是一一对应，类型不足时保留未知或允许用户覆盖，不只凭Comment猜用途。

场景、目录与图例使用同一颜色映射；同时保留形状/标签区分，选中用轮廓高亮。可切换半透明/线框，支持分类隐藏与隔离选中，隐藏只影响前端。

### C. 四视图

默认2×2：空间、XY、XZ、YZ。三个正交相机锁定旋转，只允许平移缩放；空间视图自由旋转。每个面板显示轴方向，明确观察方向约定，不能仅靠“前视/俯视”命名。

共享同一场景、对象选择、分类显隐和快照版本；各自保存相机。聚焦对象可联动，正交缩放提供可选联动。双击面板标题可最大化，再恢复四视图。

## 验收

- 已支持形状的尺寸、原点与方向和API数据对照；未知尺寸不能伪装成实测。
- 从任一视图选择同一个objectId，所有视图同步高亮；过期选择仍被拒绝。
- 修改Shift+左键等映射后实际手势生效，刷新浏览器仍保留；输入框打字不触发导航。
- 四个面板尺寸变化后没有拉伸/裁切错位；正交视图不被拖拽旋转。
- 显示设置、平移旋转、分类隐藏均不改变宿主模型或dirty状态。

依据：[Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html) 提供旋转/平移/缩放基础；完整用户自定义绑定仍需本项目实现。
