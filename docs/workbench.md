# 光学工作台使用

根目录“启动光学工作台.cmd”按需启动光学服务及官方DSH。页面由3080承载，3081只提供光学接口；完整Web与工作台共用官方session，不使用旧headless聊天。

## 连接与快照

在Zemax打开目标文件并启用Interactive Extension。顶部“连接 / 切换模型”填写目标弹窗中的Instance Number，探测后核对完整路径、对象数、单位和dirty提示，再“确认绑定并刷新”。实例不一定是1。

普通探测、绑定和刷新只读内存，不Save、不从磁盘ZMX伪装实时数据。探测候选5分钟有效；确认重新核对模型并采集，成功后保存config/optics.local.json。绑定由本项目所有工作台共享；失败保留标明过期的旧快照。

模型切换清空选择与筛选、重新适配视野；草稿文字保留，旧对象标签过期并拒绝发送。历史聊天、画板与公差配置不自动迁移。页面每3秒读取服务缓存，不每3秒调用Zemax。

## 保存当前模型

- 顶部“保存到 Zemax”：保存当前绑定模型，先刷新并核对版本。
- 连接弹窗“保存此模型”：保存刚探测到的候选模型；保存本身不切换绑定，之后可继续确认绑定。
- 用户点击即授权，不再二次确认。只支持已有命名文件；首次另存为在Zemax完成。
- dirty时先复制旧磁盘版本到当次runs/model-save/YYMMDD-NN/backup，校验哈希后Save并回读。清洁模型不重复写盘。
- 请求回执防重复执行。失败/超时/回读不一致显示未确认，不自动重试或回滚。恢复前关闭/另存当前模型，再由用户明确选择备份；ZDA不在轻量ZMX备份内。

## 视图与布局

- 半透明、实体、线框三种模式；透明度滑杆仅对半透明材质有效。颜色是显示分类，不代表真实镀膜。
- 默认上下自由/固定双视图；固定XY为X右/Y上（从+Z看），XZ为Z右/X上（从+Y看），YZ为Z右/Y上（从−X看）。反向保持上方向，左右翻转；切换面恢复0°；CW/CCW以45°步进。
- 全局方向标和原点轴独立显示。旋转/平移/缩放快捷键可配置；正交视图不自由旋转。选择后F聚焦，Ctrl多选、Shift范围选择，支持隔离和分类筛选。
- 四栏窗口缩放保持比例，默认约43.89/10.22/14.53/31.35%。手动拖边界优先相邻一增一减，碰最小宽才向外传递；不以列表中心作为锚点。
- 上下分隔线可拖；双击恢复50/50，竖线双击恢复默认比例。Esc取消本次拖动，键盘方向微调、Shift加大步进、Home复位。内部视口变高宽时同步WebGL。
- 布尔裁剪使用近似网格；构造体默认隐藏，选中可临时显示。几何语义与性能约束见[契约](contracts.md)。

## 会话与画板

选择已有会话或新建，再把镜片引用添加到草稿并显式发送。对象携带模型身份和版本；普通鼠标操作不产生提示词。完整会话链接打开同一官方session。工作台订阅官方follow/assistantStream及队列，显示实时回答、折叠思考过程和发送状态；本地发送先回显，按requestId与官方记录去重。断线自动重连并补回历史，不自动重发问题。初始加载最近120条，更多历史从完整会话查看；两端已提交消息同步，草稿分别保留。

选中聊天正文后点击“引用到输入框”，以标签插入草稿；发送时展开完整选中文字，不自动发送。引用可删除、刷新后恢复，不作为镜片对象引用。问题与引用合计上限4000字，超长提示缩小选区，不截断。此能力按社区dsh-ui-quote-selection的交互做工作台适配（MIT来源见插件NOTICE），完整Web仍使用原社区插件。

光学自动附带的模型身份折叠为“光学上下文”，不表示启用了画板。画板消息包装器使用全部slot注册项寻找下一级渲染器，避免只读优先级胜出项而吞掉用户消息。

“画板”按需弹窗，完整Web与弹窗复用同一BoardStore和transport。画板编辑器暂由N05的4173提供；正式数据在data/canvas/boards，不是.agent-canvas独立项目收件箱。保存画板不自动发送；Agent修改建议须预览/应用，拒绝可附反馈。多窗口冲突保留恢复副本，不静默覆盖。

Standard工具/权限保持官方原有机制，不额外施加工作台白名单。光学MCP查询只读；保存由用户按钮触发，副本分析按Skill与授权执行。停止回答仅取消Agent，不停止Zemax作业。

## 状态与证据

来源、采集时间、模型版本和旧快照提示必须可见。外部修改后需刷新；快照不是原子宿主事务。历史验收入口见planning/STATUS.md，当前完整文件归属见[架构](architecture.md)。


## Tx 公差

顶栏“Tx 公差”打开正式三页面板，跟随工作台浅深主题。装配页选择盲装件/耦合控制对象、维度、原生Min/Max误差及可调行程；耦合成员选择现有直接子对象。目标页选择两源和专用矩形探测器，显示全局Z、局部Z及Ref，只读距离不手填。

运行页选择独立灵敏度或Monte Carlo、None/OD/DLS补偿；草稿按modelId/revision保存，换模型不可套用旧引用。核对机械与测量约定后点击“在副本运行”授权本次配置。服务串行占用宿主，刷新/保存/其他分析会返回忙，关闭弹窗或停止Agent不取消仿真；使用运行页取消按钮。

结果显示实际进度、名义值、MC样本补偿前后、原生灵敏度端点和行程/功率有效性，不包含演示数据或补偿轨迹图。运行包路径可从记录中复制，报告和原生TXT/ZTD随包。执行和配置详见[Tx Skill](../.agents/skills/optdsh-assembly-tolerance/references/tx.md)。首次建议3个MC、1轮OD，低采样仅用于检查链路，不能作为设计收敛或良率证明。


### 自定义分析

运行与结果页增加第三种模式，共用装配、源和目标配置。先在Zemax准备参考链并刷新绑定，再勾选参考链确认；程序仍会检查实际子孙关系，发现未知随动则拒绝，不自动重引用。MC样本数沿用现有设置；先采集名义及全部未补偿MC，只补偿最后一个状态。

OD/DLS使用独立局部优化器，逐轴扫描则由脚本处理，可设轮数/初始步长比例/缩步系数；局部灵敏度围绕终点扫描。保存last-mc.zos与final-compensated.zos，原模型不变。结果提供真实MC散点、仅末样本的补偿后值、局部扫描与报告入口。只有完成且已生成报告的运行显示“打开HTML报告”；光斑数组保存在运行包。详见[自定义Tx流程](../.agents/skills/optdsh-assembly-tolerance/references/tx-custom.md)。
