## 本机备份与回退

升级前停止空闲DSH后备份至`data/backups/dsh-upgrade-20260929-235414/`：DSH持久数据（排除node_modules）、画板、工作台绑定、配置、专家生成文件/收据、根package与lock。共239个文件约20.2 MiB，备份哈希回读通过。该目录含私人配置，禁止上传或打包到公共仓库。

回退时先结束活动任务并停止DSH；保留升级后新增数据的副本，再恢复匹配旧版的项目代码、package与lock以及升级前持久数据，执行`npm ci`重建依赖后通过项目启动器启动。只降npm版本而继续使用新版专家patch并不能完成回退。升级前代码基线为`09ebc6e`；不要直接用破坏性Git命令覆盖工作区或升级后的会话。

首次npm下载部分连接迟缓；最终LibreOffice Windows原生包从镜像获取，并与npm官方dist.shasum一致后进入缓存，安装成功。未修改全局npm源。npm提示一个旧Koffi临时目录因进程占用未清理；保留为本地依赖残留，不影响已安装版本，不在本轮强删。
