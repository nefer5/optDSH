# 双视图四列工作台

2026-09-26，按方案04实现；本轮只改项目代码，不改Zemax模型。

## 布局与空间

- 左侧上下自由/固定视图，随后为镜片列表、属性栏和全高交互栏。
- 默认顶部只有紧凑工具栏与状态/显示折叠入口；文件名、对象数量、旧快照状态在顶栏可见，完整时间与revision在提示和展开区域。
- 分类筛选移入镜片列表的折叠区；三个列分隔条和上下视图分隔条可拖动，支持方向键，设置保存在optdsh.workbench.v4。
- 对象列表28px单行，编号与备注同行，长备注省略、悬停显示完整标签与类型。底纹和细色条标类别，独立描边/勾选表示多选。
- 超过250对象时使用固定行高窗口化，列表滚动不创建全部对象按钮；并不意味着3D场景也已经实现大模型LOD。

## 相机

自由与固定视图均有CW/CCW 45°和角度复位；仅绕当前视线旋转画面，不改变模型。8次回环，保持目标和缩放。
固定视图可选XY/XZ/YZ及反向观察，切换投影面重置roll；反向保留roll。每个视口常驻全局XYZ方向标，独立开关控制场景世界原点轴；选中对象局部轴仍属另一套坐标。

## 多选与草稿引用

列表或3D点击选择，Ctrl/Cmd点击增减选择；列表Shift选区以当前可见列表为范围。最后选中为属性主对象。
点击“添加选中到对话”将对象标签插入草稿光标处；不会发请求。标签可删除或点击定位；改变选择不会覆盖已有草稿。
“解释裁切”和“比较位置”是明确的草稿操作；后者将主对象与比较目标一起插入。发送才运行DSH。

引用节点保留modelId/revision/objectId；服务器核验全部引用，按真实标签重建问题，不信任客户端显示标签。纯文本粘贴不能变成对象引用。
新revision保留草稿但将旧引用标色，提交时拒绝，需要用户重新添加。最多16个唯一引用；只引用两个对象时工具另给按草稿顺序的原点差，三个以上不自动生成全部两两比较。
仍为单次只读DSH查询，不是持续多轮记忆。近期仅glm-5.3-flash，无fallback。

编辑器用浏览器原生contenteditable及编辑命令维护文本/原子引用，拦截HTML粘贴与拖放；中文组合输入期间不插入引用、不发送。原生撤销、IME和实际光标交互仍须默认浏览器验收。
