# 同会话光学工作台

2026-09-26，本期01/02/03已接入并实测。04下翻分析区未实施。

## 打开与使用

1. `scripts/start-dsh.ps1`启动官方Host，`scripts/start-optics.ps1`启动只读光学后端；画板使用已有AgentCanvas 4173服务。
2. `scripts/open-optics.ps1`打开认证后的工作台；已有官方DSH聊天顶部也可点击“光学工作台 ↗”。工作台入口由3080提供，3081保留只读数据服务。
3. 选择已有项目会话或新建会话。新会话固定当前项目模型配置（近期glm-5.3-flash）；关联后的光学会话在完整Web中也保持只读光学＋画板工具限制，不用于通用Shell/文件修改。
4. 选中镜片并“添加选中到对话”，编辑文字后发送。对象引用携带modelId/revision；过期必须重新选取，不根据编号静默绑定。
5. “完整会话 ↗”打开同一个官方session，完整页面顶部可返回工作台。两边的消息来自官方记录，工作台只作精简呈现，不再启动headless Agent。
6. “画板”按需打开弹窗，与完整Web共用同一board和工具。关闭只隐藏，编辑器保留以完成延迟保存，未发送说明也保留；只有显式发送才触发Agent。建议预览和多轮反馈主要在完整Web处理。

浏览器以用户最新Tabbit选择为准；启动脚本仍交给系统默认关联。若系统关联尚未改好，可直接在已认证的Tabbit中打开 `/api/optdsh-workbench/view`。

## 状态与边界

### PC布局与消息呈现（Figma修改意见1）

- 默认四栏按有效内容宽度同比缩放，约为3D 43.89%、目录10.22%、分析14.53%、会话31.35%。基于Figma的792/166/236/430，将3D原宽度的10%转给会话；不是将3D减少10个百分点。
- 手动拖动移动分隔线：先只调整相邻两栏，另一条边界及远端栏不动；达到最小尺寸后才向外推移。窗口缩放仍按已保存比例分配。会话栏可扩大到屏幕一半，详见[面板分隔线](panel-resizing.md)。
- 双击任一竖向分隔线，或聚焦后按Home，恢复默认四栏比例。左右方向键按比例调整。新v5布局保存比例；旧v4固定像素宽度不迁移，只沿用主题和上下视图分隔位置。
- 消息字号13px，用户气泡靠右、助手靠左，使用不同底色；身份只保留无障碍标签，不占可见标题行。输入区与消息区分色，空气泡不显示。
- 新旧画板提交及明确的Excalidraw场景JSON折叠到低对比详情；普通JSON配置/代码不被误隐藏。消息原始记录不改写。
- 已在Tabbit验证1280×800、1920×1080、3440×1440；3440宽屏会话拖到1720px且刷新后保留。仅考虑PC，低于工作台1050px最小宽度的窗口不承诺无横向滚动。

- 工作台按可见状态轮询官方历史快照，约1.8秒刷新；显示已落入官方记录的文本，尚未接入逐token流式呈现。完整Web保持官方流式显示。
- 草稿用当前标签页sessionStorage按session隔离；不覆盖另一窗口输入。画板恢复沿用原编辑器本地副本与版本冲突处理，不是CRDT实时合并。另一个窗口改图时，旧版本保存会拒绝，保留恢复副本；在完整画板中重新打开/核对。
- 已提交请求以requestId记录幂等回执；不确定交付不自动重发。官方队列、停止、历史和模型状态仍由同一个Host管理。
- “停止回答”只取消该Agent当前轮，不代表取消Zemax仿真；本期没有开放Zemax写入或公差执行工具。
- 3081旧聊天/旧画板提交端点返回410，原`.runtime/optics-conversations.json`与旧DSH记录未删除。不要在旧headless入口和官方Host同时resume同一session。
- 光学后端不可用时，可继续查看会话和画板；涉及当前镜片事实的提交会报错，不能用旧快照冒充实时状态。

## 实现入口

- `plugins/optdsh-workbench`：官方认证HTTP页面/资源、只读光学代理、会话绑定、发送/历史/取消、完整Web跳转。
- `web/optics/workbench-agent.js`：精简呈现和交互；`workbench-layout.js`保留列宽/主题控制，三维与CSG代码复用原实现。
- `web/shared/canvas-bridge.js`：完整Web与临时弹窗共用的画板通信，校验origin、frame source、channel并锁定session。
- `plugins/optdsh-agent-canvas`：仍拥有唯一BoardStore和画板工具。消息装饰监听官方slot延迟注册，镜片/画板技术上下文默认折叠，不重写原始历史。
- `.runtime/workbench-bindings.json`只记录工作台绑定、引用与发送回执；官方DSH会话是聊天事实源，不再另存回答副本。
