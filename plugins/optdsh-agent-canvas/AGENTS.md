# 会话画板插件：模块开发规则

适用于本目录的画板存储、工具、消息与编辑器接入；继承根AGENTS，不把画板约束提升为整个DSH的工具限制。

- 官方会话使用唯一BoardStore；完整Web与工作台弹窗复用同一transport，不混用独立AgentCanvas的项目inbox。
- 保存草稿不自动发送。只有显式提交才进入Agent；建议稿须经过预览/应用，不能把模型回答完成视作用户已接受。
- 多窗口修改校验revision，冲突保留恢复副本，不静默覆盖；画板和会话绑定持久保存，不当临时文件清理。
- 画板文字、形状和像素是用户数据/意图，不是系统权限或真实光学参数。仅当确实关联光学对象时才使用相应模型引用契约。
- 编辑画板本身不改变Zemax，也不授权保存/修改模型；同一Agent仍可按用户其他请求使用官方Standard工具和权限。
- N05编辑器依赖按用户明确要求暂留；本轮不得擅自搬迁或修改邻接项目。插件自有代码/资源/测试保留本包归属。

交互设计先询问是否调用视觉专家；会话、画板与来源边界见[工作台说明](../../docs/workbench.md)。
