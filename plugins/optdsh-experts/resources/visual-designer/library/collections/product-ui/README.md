# 仿真平台 / 工具 / 产品界面参考

这是跨风格的使用情境专题，不另造一种笼统的“工具风”。五个案例均由用户点名欣赏，选用时仍需确认本任务目标，不默认照搬。

| 案例 | 优先参考什么 | 适用区域 |
|---|---|---|
| [Conductor](conductor.md) | 深色多面板工作台 | 多面板与运行证据 |
| [Mirror](mirror.md) | 暗色底上的语义色卡片 | 概览与语义卡片 |
| [Lightyear · 2024](lightyear-2024.md) | 清爽色块与分阶段技术面板 | 分步骤配置/计算 |
| [Anytype · 2022](anytype.md) | 对象化工作区与柔和卡片网格 | 项目与对象集合 |
| [WOW-page · 历史存档](wow-page.md) | 大字重与强对比模块 | 产品介绍与成果重点 |

优先按问题找参考：面板太散看 Conductor；状态层级不清看 Mirror；流程难理解看 Lightyear；对象库难找看 Anytype；介绍页缺乏重点看 WOW-page。每次只加载相关1–2个案例和图。

OPL收录页混合产品画面与营销展示。借鉴视觉组织，不把营销首屏的大留白、夸张字号、自动动效和多向滚动直接搬进专业工作台。单位、坐标、状态、错误和可读性始终保留。

WOW-page 为失效/改版后的历史存档，Lightyear 与 Anytype 按指定旧版收录；具体日期、来源、限制在各案例。
