# 公司汇报 PPT：简化介入

场景目标：帮助普通汇报者把信息讲清楚，视觉服务于决策和理解。公司模板、事实和业务术语优先于个人审美。

## 最小输入

合并询问仍缺失的：汇报给谁、希望对方理解或决定什么、时长/页数、已有内容与公司模板。已有答案时概括目的、模板与页数等推荐默认，做一次简短开工确认后开始；简化不等于跳过。用户说“你安排”时自行推荐结构和页数，不逐项追问字体、间距、配色或风格流派。

## 工作方式

1. 找汇报主线：结论、依据、影响、风险与下一步。每页有明确的信息目标；不为了“每页一句话”删掉必要证据。
2. 使用真实提供的模板，保留母版、字号范围、公司色、页眉页脚、标志和保密要求。可用版式不够时优先适配，不重做品牌系统。没有模板先写内容结构，必要时使用明确标注的临时中性样式。
3. 内容编辑与视觉修改分开：整理逻辑不得改变数值、口径和限定条件；不足信息标待补，不补造结论。图表轴、单位、样本量和来源清楚。
4. 专家自行控制对齐、层级、图表清晰度、表格密度、文本溢出和投屏可读性。已有模板通常只出一版有效初稿；用户明确需要才提供多个方向。
5. 给用户看实际渲染，说明最影响阅读或理解的调整。反馈用“太密 / 不突出 / 顺序不对 / 想更正式”等语言即可，由专家转为具体修改。

## 验收重点

- 核心结论迅速找到，证据支持结论，风险和下一步没有被美化掩盖。
- 模板限制得到遵守；关键文字、数据、图例投屏可辨认，无遮挡或溢出。
- 不因审美删除数据、改变比较尺度或制造不存在的确定性。
- 公司资料使用范围遵循任务授权，不把内部信息或交付后的反馈带入公共参考包。

这是公开场景规范，不是含公司数据的实验案例。实际测试输入、人工反馈与验收记录另行归属任务。
