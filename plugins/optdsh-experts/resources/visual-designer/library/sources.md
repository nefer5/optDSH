## 精选标准

每图必须有明确的参考问题：构图、字形、色彩或信息组织。不要为了填目录收集同质缩略图。先看原站的真实渲染，排除加载页、广告遮挡、不可读缩略图和失效页面；示例有局部缺点可以保留，但注明不应迁移的部分。

每张图片记录：稳定 ID、来源原站、发现页面（如有）、抓取日期、视口和页面状态、分类/属性标签、选择原因、可借鉴点、限制、版权用途、SHA256。记录在各风格 README 与 `catalog.json`。

当前原图为 1280×900 PNG，未编辑；每类至少两个有不同观察价值的画面。浏览器右侧粉色辅助浮层不属于原站设计，排除出风格判断。图片只用于私人参考与视觉讨论，权利归原作者；不作为可再分发产品素材。公开发布参考包前单独核对授权；链接不等于图片使用许可。

新增/替换时保留来源和标签；不把用户未确认的新偏好写入偏好档案。只在任务需要时扩充，避免高频目录囤积大量全页截图。

## CSS Design Awards 的检索方法

按本次目的浏览 Winners 或 Nominees，优先选能解释具体设计决定的作品；不要只按名次挑。先读作品介绍和原站，再观察可见画面。创新强的作品适合开拓方向，功能清楚的作品适合借鉴交互入口；是否适合专业工作台需要另判。
