# 光学工作台插件：模块开发规则

适用于本目录的实现及光学工作台交互设计；继承根AGENTS的公共规则，不把以下光学约束扩展到所有DSH会话。

- 本插件负责呈现、选择和协议适配。光学模型/计算权威在Zemax与光学服务，网页近似几何、草图和光线示意须与真实状态区分。
- 对象选择与提交携带modelId/revision，刷新/换模型使旧引用失效，不按OBJ号静默重绑。面向用户的光学对象引用使用编号[当前Comment]；空备注与未记录分别标识。
- 镜片选择、画板标注和鼠标移动是草稿，显式发送才进入Agent。提示词草稿、运行监控和结果展示分开；回答完成不表示仿真完成或用户接受建议。
- 与官方Web使用同一sessionController及Standard权限。不得以“光学工具只读”为由新增整个Agent的Shell/文件/Skill白名单。
- 保存按钮只对其标明的目标授权Save，不授权参数修改；普通探测/绑定/刷新不保存。实际版本检查、备份、Save和回读由packages/optics执行，不在前端另做写入口。
- 性能验收采用用户当前约定的负载：约每分钟一次参数修改。这是验收基线，不是限制用户操作频率。布尔在Worker中计算，依赖缓存有上限并释放资源；相机/配色不重算布尔，多视图共享几何。
- 窗口缩放保持栏宽比例；手动分隔线优先调相邻面板。内部视口尺寸改变必须同步WebGL重绘。
- 插件专属资源和测试在本包，画板经optdsh-agent-canvas的transport复用；不另存第二份会话或画板事实。

细节见[工作台操作](../../docs/workbench.md)、[几何与数据契约](../../docs/contracts.md)。涉及界面设计先按根规则询问是否调用视觉专家。
