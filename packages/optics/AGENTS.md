# 光学公共包：开发与执行边界

适用于本包的连接、采集、保存、分析和报告实现；从Skill或其他目录调用这些能力时同样约束实际Zemax操作。普通DSH文件任务不因此成为只读。

- Zemax与回读结果是光学事实源。模型身份/revision、单位、坐标、参考对象和旋转含义必须在数据边界明确，不能凭截图决定写入。
- 本包使用项目独立Python环境和本地连接代码；N02可读作参考，不导入其代码/环境，不修改相邻项目。
- 同一模型的共享写入串行，身份/版本不符、宿主忙或恢复条件不满足时停止相应光学操作。
- 区分只读、CopySystem、显式Save和原位参数修改，完整门禁见[光学操作规则](../../docs/rules.md#光学操作门禁仅适用于zemax资源)。只读/副本流程不自动保存主模型。
- 显式保存只针对按钮指定模型；备份的是保存前磁盘版本，不是未保存内存。失败或结果不确定不自动重放，也不以旧磁盘副本冒充可恢复完整内存状态。
- Agent取消与仿真取消分开；执行器独立记录作业状态、清理结果和输出版本。不要把进程退出或API成功标志单独当成光学正确性证明。
- 通用确定性代码不导入Study，不硬编码对象编号、H/V零位、控制系数、指标阈值或扰动值。业务选择由Skill与当次配置负责。
- 运行包与报告复用本包公共实现；研究数值口径在领域契约/Skill，不在平台文档复制第二套。

使用[光学契约](../../docs/contracts.md)与[运行包规范](../../docs/runs-and-reports.md)。回归优先离线边界，真实Zemax测试按具体任务授权执行。
