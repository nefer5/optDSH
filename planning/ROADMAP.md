# 路线与验收

每阶段先获得可检查证据，再推进下一阶段。没有承诺工期。

| 阶段 | 交付 | 验收 |
|---|---|---|
| M0 初始化 | 需求、约束、架构、合成接口样例、Git | 文件可查，样例引用一致，状态无虚假能力声明 |
| M1 运行基线 | 固定 DSH、选定非顶尖模型、官方 Web/Standard | 文本与工具调用实际通过；记录版本与实际能力；按部署场景核验出口；图像单独标记结果 |
| M2 只读光学桥接 | 优先复用opt-assist连接/读取，加场景规范化、身份和revision适配 | 对照 Zemax 核对对象、参考关系、世界坐标及单位；缺字段不冒充0；忙碌和断连可识别 |
| M2.1 查看器升级（首版已交付） | 参数化近似形状、细分配色、可配置相机导航、2×2四视图 | 已做浏览器交互验收；特殊形状物理意义待专家检查，布尔结果仍为标记 |
| M2.2 常用布尔裁切（首版） | A&B、机械平边、Worker和有界缓存 | 已有真实快照6组网页通过；实时宿主NotAuthorized，专家几何对照待验 |
| M3 专家只读闭环 | 独立场景组件＋DSH薄插件：简化三维、对象选择、显式提交、独立运行视图 | 点击真实对象提问，答案来自该对象该版本；过期引用被识别；日志不挤占交付 |
| M4 可控修改 | 建议、确认、执行、回读、恢复 | 版本冲突拒绝，重复命令不重复执行，失败可回读并恢复；独立报告仿真取消 |
| M5 领域质量改进 | corner case 集、专家案例、对照评测 | 比较完成率、错误对象操作、人工介入、重复失败、耗时与费用 |

## 首个真实闭环（M3）

用户新增反馈见 [M2.1升级建议](../docs/archive/viewer-upgrade-proposal.md)，首版实现及限制见 [操作说明](../docs/guides/viewer-controls.md)。

M2复用清单及M3分层建议见 [opt-assist复用备忘](../docs/research/opt-assist-reuse.md)。M3可先用冻结/合成快照推进界面；正式M3验收仍需M2真实数据链路。

使用经授权的非敏感小型非序列模型。网页点击对象，询问相对参考对象的姿态。Agent 调用只读工具；主区回答，运行区显示对应工具、对象和模型版本。专家改变选择或刷新模型后，不能让旧引用静默指向新对象。

## 后置事项

精确几何、复杂 CAD、追迹大数据、AgentCanvas 深度整合、持久案例检索、多 Agent 和 Code 模式评估均按证据推进。先明确第一个模型/对象类型，再选渲染和几何管线。
