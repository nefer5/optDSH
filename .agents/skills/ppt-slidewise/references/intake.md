# 轻量意图询问：三选项＋自定义

先理解现有材料，再选最有价值的1–2题。每题尽量给三个易懂选项；允许只回“1a、2b”，也允许直接自然语言回答。选项不排除用户自定义，不把推荐项当用户已选择。不要先抛出整套问题、专业术语、精确页数或完整策划表。

## 小题库（按需选，不是全问）

| 要弄清什么 | a | b | c | 自定义输入提示 |
|---|---|---|---|---|
| 主要用途 | 同步进展、说明现状 | 比较方案、支持决策 | 讲解知识、分享方法 | 其他用途或你希望对方带走的一点 |
| 主要听众 | 领导/决策者 | 熟悉背景的同事/技术同行 | 不熟悉背景的新同事/其他听众 | 具体听众及已知背景 |
| 内容体量 | 简短报告，约5–10分钟 | 常规报告，约10–30分钟 | 长篇内容，30分钟以上或完整阅读材料 | 自定义时长、页数要求，或暂时不确定 |
| 表达重点 | 先讲结论与行动 | 讲清证据、比较与推导 | 先讲背景与理解 | 特别想强调或避免的内容 |

已知“给领导看”就不重复问听众；若用途未知优先问用途，可搭配体量。若用户已明确用途和体量，只复述方向并补最关键缺口，不为了凑两个问题继续问。阶段内没有信息缺口时无需提问。

分钟只是深度参考，页数在组织内容后估计。第二档在10分钟边界与第一档相接，无需纠结边界；用户说10分钟时按内容密度协商，不要求重新选择。长篇可能是阅读材料，不强加演讲时长。

## 自定义入口

- 宿主有结构化提问控件：每题三个选项，使用控件自带的自由输入框，不再添加“其他”伪选项。
- 普通聊天：每题a/b/c之后写“也可以直接补充自己的要求”，不伪称已有可点击输入框。
- DSH中用户希望点选/填写时，使用本Skill附带的简短声明式表单，由已有dsh-forms渲染；选择框旁提供自定义文字输入。无需新写界面。
- 自定义文字是对选项的补充或修正。明显冲突时只追问冲突点，不默默覆盖；选项为空但自定义明确，照样可以推进。

## DSH简短表单

使用前读`.agents/skills/dsh-forms/references/skill-input.md`。默认先自然聊天，不为简单两问强制跳转页面。要可点击表单时：

```text
node plugins/optdsh-forms/lib/cli.js create --config .agents/skills/ppt-slidewise/config/intake.example.yaml --form .agents/skills/ppt-slidewise/ui/intake.yaml --brief
node plugins/optdsh-forms/lib/cli.js read --id <返回ID> --brief
```

样例只含“用途＋体量”两题，每题三个选项和一个自定义输入框。没有预选答案，空值不代表默认选择；只把submitted视为用户回复。不要自动提交、不轮询，用户提交后回原聊天继续。已有答案较多时为当前请求裁剪表单，不能让用户重复填写。此入口不触发PPT生成，不改变策划确认步骤。
