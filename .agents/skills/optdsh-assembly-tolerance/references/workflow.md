# 两阶段装调分析

用户确认于2026-09-26：Tx使用H向D86全角，光源6D可调；Rx使用矩形H/V光斑尺寸，SPAD 6D可调。

## 分层

镜片组装入镜筒产生内部误差；镜筒整体安装误差另列，不与内部每片误差重复抽样。
“整体耦合”阶段实际移动的是光源或SPAD，不能默认移动镜筒，更不能将所有镜片重新优化。
旋转以哪个机械基准点为中心、各自由度在哪个坐标系定义，必须在采样或优化之前明确。

## 指标边界

- Tx H-D86：确认角度单位、远场/角域获取方式、H轴基准、86%能量分母、居中对称/最短区间/投影等具体口径。不将直径D86的其他定义自动套入H向。
- H/V的测量坐标系需与补偿动作区分：特别是SPAD绕光轴旋转时，不得在未约定的情况下同时旋转评价坐标以人为改善某一方向指标。
- Rx H/V：矩形两个方向的尺寸只是表示形式，仍需明确全光线包络、能量包络或强度阈值。H和V独立86%投影不等于二维矩形内86%能量。
- 裁掉大部分光线可能让剩余光斑变小。补偿时要同时报告捕获能量、有效光线数和光斑偏移，防止把丢光误判为成像改善；约束阈值由专家指定。
- 缺少光线、全失光、无收敛、越界补偿均为显式结果，不能自动剔除使良率虚高。

## 推荐阶段

1. 名义模型验证：光源、谱线、光线数、接收面、参考轴、指标计算一致。
2. 单因素：优先内部偏心/倾斜/间隔与已关注加工参数，每项分别观察未补偿和允许补偿后的变化。
3. 联合抽样：明确分布、截断、相关性和共用机械误差；固定同一抽样样本比较两个阶段。
4. 装调可行性：补偿量/范围利用率、残余指标与上下限、失败类型；不只给均值或单一“通过率”。

当前Tx未补偿单因素副本试跑已实现，见[Tx流程](tx.md)；Rx执行、完整6D补偿及Monte Carlo执行器尚未实现。以上是拟议方法，不是已经执行、授权生产模型写入或经过实物验证。
