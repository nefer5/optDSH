# Tx 原生公差工作流设计

2026-09-27 · 方案与交互原型；尚未接入正式执行器。用户确认：die1/die2各一个专用探测面；首版NSDD RMS宽度；连续补偿，只配置行程，不配置步长。

后续澄清：用户要求先对齐Zemax原生输入。盲装误差以Min/Max为主输入，σ仅作派生提示或可选的对称范围输入助手。分布、截断倍数和样本数遵循原生统计设置。下文涉及σ输入处均指该可选助手，不是强制主入口。

## 目标与交付边界

保留统一装调Skill入口，将Tx分支逐步切换为Zemax原生TDE + Merit Function + Tolerancing工具。用户在工作台结构化配置，Skill解释/补齐配置并启动确定性编译与执行工具。Monte Carlo抽样和每样本补偿由Zemax执行；不能用旧Python逐项扰动冒充原生公差。

当前仅设计。已实测证据仅覆盖合成小模型的TNPS、NSDD、无补偿Sensitivity和3次MC；尚未实测CNPS补偿、多die目标、行程约束、刚体映射和结果逐样本配对。本设计和YAML不能交给旧run_tx_pilot执行。

可交互原型：[工作台配置原型](../../../../plugins/optdsh-workbench/prototypes/tx-tolerance/index.html)。示例对象和参数均为演示数据；原型不连接Zemax。配置契约草案：[tx-native.example.yaml](../config/tx-native.example.yaml)。

## 用户输入契约

1. 模型：绑定当前工作台modelId、revision、实例、SystemID；配置与模型切换不自动迁移。
2. 盲装件：从对象目录多选并添加；每个机械实体可包含多个模型对象。显示OBJ编号[Comment]、类型、参考对象和关联子对象。每维选择是否启用，输入相对名义值的Min/Max误差，位置mm、转角deg。新增组件默认6D，范围不默认填成制造规格；未启用轴不编译公差项。可选按σ助手生成对称范围；不把非对称输入静默改成对称。
3. 耦合件：选择一个或多个可调整机械组，未指定维度默认x/y/z/Tx/Ty/Tz。每维填负/正行程（相对耦合基准），以−/+数值显式展示。首版连续优化，无步长字段。未填行程或坐标/枢轴未知只允许保存草稿。
4. 目标：只评价die1与die2，每颗die分别选择源对象、专用探测器和H映射。传播距离不手填，读取所选探测器的Z值，只读显示Z、单位、参考对象和坐标来源。其他die不参与目标不代表它们可机械独立运动；四die若属于同一封装，仍作为一个刚体耦合。
5. 计算：RMS H宽度；每die归一化尺度/权重、可选验收上限、最低捕获能量有效门槛。默认建议两die等权；验收要求两个分别达标，不能只看总MF。
6. 运行：先名义校验，再Sensitivity/Monte Carlo；MC样本数、分布、截断倍数、随机种子、每源光线数、优化方法/循环数。原型预填值只是示例。追迹随机种子与制造误差抽样种子分开。

## 误差与机械语义

- 默认：相互独立、截断正态，截断倍数n=2以贴合Zemax默认；允许显式改3等整数。分布中心误差=(Min+Max)/2，母正态σ=(Max−Min)/(2n)。非对称输入允许但必须提示产生的中心偏置。截断后实际样本标准差通常较小；若输入实测截断后σ，必须另外转换。
- 编译`STAT(0,n)`，每个启用轴生成`TNPS(Surf=1,Object,Code)`，Min/Max按用户输入；Code=1..6对应x/y/z/Tx/Ty/Tz。n建议限定1..10；Min和Max有限且Min<Max。按σ助手显式生成Min=−nσ、Max=+nσ；σ须有限且>0。
- 灵敏度分析使用Min/Max两个极值，不是±1σ。MC按STAT生成全部误差的组合。两者在报告中分开。
- 机械实体≠Boolean构造体≠NCE对象。引用链必须核对；不能把Boolean的每个基础面重复加公差，也不能盲动一个镜片导致后续组件跟随。
- 组内成员使用公共父坐标或在副本上建立经验证的刚体控制结构；新增父对象、重引用与对象编号变化后必须重建编译映射。编译前后核对世界矩阵，名义几何不允许变化。
- 明确轴所处坐标系和绕转枢轴。UI展示“相对装配基准”的机械增量；后端转换为NCE实际坐标。不能把六个欧拉角/平移的独立写入直接当成任意枢轴刚体变换。

## 补偿与行程

- 使用`CNPS(Object,Code,Surf=1)`定义位姿补偿器；其参数顺序与TNPS不同，须通过本机API回读测试。
- NSC原生模块忽略补偿器Min/Max本身的范围；应在MFE生成适用的位姿下/上界操作数。位置使用NPXG/NPXL、NPYG/NPYL、NPZG/NPZL；倾角使用NTXG/NTXL、NTYG/NTYL、NTZG/NTZL。位置Ref?坐标语义与倾角的参考语义须单独校验。NPGT/NPLT是对象形状参数边界，不能拿来直接替代6D位姿限位。
- 这些MF边界是优化惩罚，不等于求解器硬约束。每次结果必须检查全部补偿量；越界、未收敛、缺能量的样本独立标无效/失败，保留计数与分母，不把它们删除后抬高良率。
- 行程相对基准建议为名义装配零位；名义耦合后的剩余行程一并报告，不能每个MC样本重置名义零点从而获得额外行程。
- 两die共享一次联合补偿。可选OD或DLS（NSC先评估OD），优化循环数在高级设置中。光斑噪声、像素插值、光线数收敛会影响可优化性。
- 先在合成模型验证：CNPS实际可变、极小行程边界确实约束/越界被识别、共享刚体补偿同时影响两个目标；再接真实模型。

## 给用户的补偿方法说明

一次制造样本先确定并固定盲装误差，随后仅调整CNPS定义的耦合自由度，使两die共同评价函数改善。100次Monte Carlo表示100套误差组合，每套都可有多轮补偿优化；不是100次位置步进。Sensitivity则逐公差极值评价并按所选方法补偿。

- None：忽略补偿器，作为装完不调的性能对照。
- Optimize All (OD)：正交下降，不依赖数值导数；对像素化/含噪NSC目标通常更适合作为初始选择。
- Optimize All (DLS)：先一轮OD，再阻尼最小二乘；利用局部响应估计改善方向，平滑目标可更高效，具体需相同样本对照。
- Paraxial Focus属于一般公差帮助中的近轴调焦选项，不作为本NSC双die耦合流程的选择。

这两种算法都是局部连续求解，不保证找到全局最优；行程、捕获功率和收敛另行验收。名义、同一误差样本未补偿、补偿后应分别报告，避免把优化困难当成制造缺陷。

## RMS宽度与发散角

每颗die一个探测面，不做两探测面宽度差，也不把die1/die2两个宽度相减。每个目标单独清探测器、追迹对应源，再读取目标探测器：H对应局部X时`NSDD Pix=-10 Data=0`，对应局部Y时`Pix=-11`。H不是未经校验的固定X轴；首版只接受明确对齐的局部X/Y，任意斜方向留待协方差投影能力。

NSDD返回σ_H而非全宽。首版目标定义为：

```
q_i = σ_H,i / L_i                 # 近轴RMS等效角宽度，rad
q_i[mrad] = 1000 × σ_H,i[mm] / L_i[mm]
```

这是平面光斑对距离的角宽估计，不是直接从光线方向计算的RMS角度。仅在远场/可忽略出射束宽、探测面垂直视轴且H轴正确时近似成立。本场景按用户指定读取专用探测器Z值作为传播距离的输入，只读显示原始有符号Z和参考对象，不允许页面手填覆盖。执行前核对该Z所属坐标系确以测量起点为零、沿传播方向；只有这项模型约定成立才能令L=Z。负值、零值或坐标约定未确认时不静默取绝对值或生成有效角度。折叠光路不能拿世界坐标Z差或对象原点欧氏距离代替传播距离。对于大角度、显著离轴、近场或补偿改变距离的情形，先定义严格几何计算并验证，不能把atan(σ/L)称为严格RMS角。

若另行显示4σ等效全宽，其角宽估计为`2 atan(2σ/L)`；只有高斯分布时才与1/e²全宽对应。本版默认不显示，以避免名称混淆。D86/FWHM与RMS不能默认为同一规格。

副本MFE设计顺序：

1. die1块：NSDD清空 → NSTR(源1) → NSDD宽度与功率。
2. die2块：NSDD清空 → NSTR(源2) → NSDD宽度与功率。
3. 组合尺度：距离固定且已校验时，可直接把归一化因子放入宽度行权重，避免不必要的自定义求解器。长度可变时需要原生算术/位置读数构造比值并本机验证。
4. 补偿行程惩罚、捕获功率约束。仅在相应源可独立控制且专用探测器不交叉污染时允许共享一次追迹；首版用两段追迹更清晰。

推荐联合目标为`J=Σ w_i(q_i/s_i)^2 + P_range + P_flux`。s_i是固定标定尺度或规范上限，不每样本重新归一化。固定L时，NSDD行权重可取`w_i/(L_i² s_i²)`（单位统一）。Zemax最终返回的MF含自身权重归一化及惩罚项，不直接当作某一die的角度；必须另行输出两个die的物理指标。目标最小化与达标阈值分开：未填规格只输出分布，不输出良率。

捕获功率必须有门槛；否则截光、光线丢失会造成RMS虚假缩小。首版建议门槛为“名义功率保持率”`P_die / P_die,reference`，分母取冻结的名义参考模型同源同探测面的接收功率，并在所有样本中保持不变；不是发射功率，也不能用每个样本自己的功率归一化。配置字段`minimumNominalPowerRatio`。另报告接收/发射通量比与边缘功率，以区分光学损耗和截光。名义值为零/非有限、功率不足等都禁止启动正式MC。

## 工作台交互

- 顶栏功能按钮“Tx 公差”，打开宽幅模态配置面板；不改变四栏比例。关闭保留草稿，模型改变显示过期；按钮旁可显示当前运行状态。
- 三个标签页：装配配置（盲装件+耦合件）→ 目标（两die目标）→ 运行与结果（运行设置、检查、作业状态及结果）。状态页为独立页面视图，切页不重置作业。跟随工作台浅色/深色主题；原型独立演示主题，不修改正式工作台的已保存偏好。
- 添加对象支持目录选择和“使用工作台已选对象”；多对象明确选择“分别添加”或“同一刚体组”，不自行推断。选择器显示编号、备注、类型与引用关系，非法类型给原因。
- 每组件使用横长竖短卡片，六维横排列，每维一个开关与Min/Max或负/正行程输入；窄屏重排而非把字段缩到不可读。盲装与耦合分区但在同页；未启用轴灰显，批量填充须用户点击。盲装Min/Max是误差范围，耦合负/正行程是可调范围。σ可选助手只生成对称公差，输入非对称值时显示中心偏置。删除仅影响草稿。
- 目标页紧凑展示两个die目标卡、只读探测器Z、H轴及功率门槛；运行设置和检查统一放第三页。光源机械组与评价光源分别呈现。
- 运行与结果页检查区展示缺项、有效公差维数、补偿维数、两个目标、预计设置。高级折叠显示TDE/MFE编译预览、坐标映射和配置原文，不要求用户手编操作数。
- 概念说明默认折叠：最低名义功率保持率=P当前/P冻结名义，例0.95表示至少保持95%的名义接收功率，不是PDE或发射效率；OD/DLS说明连续优化的搜索方式，行程为独立约束，不将算法名称当“已收敛”证明。
- 正式动作：保存草稿 → 名义校验（副本） → 生成并检查原生配置 → 在副本运行。一次显式执行确认覆盖该冻结配置；变化即失效。明确按钮“在副本运行”；“写入活动模型”是未来单独动作，不隐含在生成配置里。
- 运行与结果页区分未运行、排队、创建副本、名义追迹、灵敏度、MC/补偿、导出、回读恢复、完成/部分失败/取消。显示当前阶段、已完成样本/总数、耗时、最后更新时间；后端没提供数值时显示未提供，不伪造精确进度或剩余时间。演示模式使用独立标识和合成计时，不能视为真实Zemax进度。独立停止仿真按钮，不跟随停止Agent。部分失败保留当前结果，未确认取消完成不能显示已停止。
- 结果按die分别展示名义/未补偿/补偿后分布、最差样本、行程利用率、越界/失效/不收敛率。补偿前后必须同一制造样本配对；用原生tolerance script的报告/优化流程或保留MC样本再回读，先验证，再选择具体接线。两次独立随机运行不能声称配对。

## 独立灵敏度分析

运行与结果页包含“Monte Carlo公差”和“单独灵敏度”两个运行模式，共用同一份装配与目标草稿。选择模式不复制或覆盖公共配置；每次运行冻结配置版本、模式与补偿策略，结果绑定自己的run和版本，修改草稿后不能把旧结果标为当前结果。只允许同一宿主一个作业；运行时切换模式不重新标注已有作业或误关联其结果。

### 单独灵敏度

- 原生设置为Sensitivity、Monte Carlo NumberOfRuns=0；官方明确0可省略Monte Carlo。运行前以本机接口回读确认，不能只将网页输入框隐藏而后端仍采样。
- 逐一将启用盲装轴置于其Min、Max，其他盲装误差保持名义；记录名义、负/正端点的die1/die2值及相对名义变化。
- 提供“不补偿”与“补偿后”策略。前者使用None，后者使用共享耦合件及OD/DLS。补偿后灵敏度表示可调整后的残余影响，不能与未补偿值混排而不注明。
- 不要求MC样本数或制造随机种子，仍需固定/记录追迹条件。表格显示OBJ[Comment]、轴、Min/Max及单位、每die结果；按指定公差范围内的最坏目标变化排序。该排名依赖公差幅度，不等于单位位移/倾角的导数。
- 首版原生灵敏度只以端点作评价，不把Min/名义/Max连线宣称连续扫描证据；若需要整条响应曲线需明确新增扫描采样。

用户已取消补偿过程轨迹图，本版不设计或采集中间优化路径；结果保留名义/补偿前后对比、最终补偿量/行程利用率及灵敏度端点影响。

## 实现拆分与验收

1. 本轮：方案、YAML设计样例、原型。旧Skill执行器保持有效，新设计标不可执行。
2. 确定性编译器：放packages/optics；校验YAML版本、绑定、对象映射、坐标/组、σ/行程、目标。生成原生TDE/MFE及映射清单；保留原副本MFE，不覆盖主系统。加入真实解析/非法配置拒绝测试后才称支持新YAML。
3. 原生执行器：公共串行宿主调度、CopySystem、前后状态证据、取消/超时、ZTD/TXT/API结果一致性。不能只看Succeeded；上一轮已发现完整路径OutputFile会无实际产物，采用文件名并核对落盘目录。
4. 工作台正式组件：plugins/optdsh-workbench拥有UI/API适配；当前原型的示例状态替换为带身份的真实快照。业务Skill保持唯一统一入口，Tx指向新执行器，Rx独立不改语义。
5. 每次运行冻结源YAML/解析配置、模型身份与字段哈希、生成MFE/TDE、源选择/距离/H映射、抽样/追迹种子、优化设置、原生结果与报告。Study归属按公共run规则。

正式启动前仍需确认：真实对象与机械组；装配轴/枢轴；每die距离基准与H映射；σ/截断倍数；补偿行程；捕获功率门槛；若需良率，再填两个die各自的规格上限。
