# 原生Tx实现边界与配置职责

当前入口见[Tx流程](tx.md)与[模板](../config/tx-native.example.yaml)。公共实现支持两个配置目标、专用矩形探测器和已确认的global-z近轴RMS距离模式；这是已实现的算法适用范围，不是所有课题应采用的评价标准。

目标轴、对象、归一化尺度、权重、功率门槛、机械组与行程必须来自所选Workspace配置。缺少定义或用户要求的算法超出范围时明确缺项/不支持，不能把其他研究的对象、封装数量或历史距离当作默认值。

通用实现保留：TNPS/CNPS编译、名义与误差样本的连续补偿、固定名义功率分母、范围惩罚及回读越界检查、Sensitivity与MC分流、同一样本补偿前后配对、CopySystem与身份/恢复核验。历史项目的具体目标及界面讨论不构成公共产品规则，已随课题资料保存。

本轮未改变底层求解器的目标数、global-z限制或追迹算法，也未重新实测真实Zemax；其他测距几何和目标数量需要专门实现与验收，不能靠修改提示词宣称支持。
