# 分类体系：风格家族 × 属性标签 × 使用情境

## 一、风格家族（当前五类，支持以后扩展）

| 目录 | 日常说法与识别特征 | 常见适用情境 | 易犯错误 |
|---|---|---|---|
| minimal | 克制极简：少元素、清楚主次、精确比例、有限强调色 | 产品展示、专注阅读、简单任务入口 | 减掉必要内容；把所有字做浅灰；只剩大片空白 |
| editorial | 编辑叙事：有节奏的图文、标题气质、跨栏与图片裁切 | 专题、文化内容、作品故事、报告封面 | 为照片牺牲文字对比；把工作台做成杂志 |
| functional | 功能理性：稳定网格、语义分组、可扫读文本、清楚入口 | 服务门户、工具、表单、专业信息与工作台 | 把“功能”当作可以忽略排版；过多框线 |
| expressive | 鲜明表达：大比例对比、显著视觉重心、个性图形或材质 | 品牌、活动、创意作品集、营销叙事 | 所有元素抢注意力；把夸张动效当作创新 |
| technical-craft | 工程手作感：制图网格、刻度/编号、纸面颗粒、领域图像 | 工程产品、技术作品集、科研内容 | 细字过小、装饰线太多，照搬加载动画 |

这五类是首期检索入口，彼此并不互斥。例如专业工作台可用 functional 构图和 minimal 装饰；作品集可有 editorial 叙事与 expressive 标题。Heron 作为 technical-craft 的具体样例，Anthropic 作为 editorial 中偏人文科技的一支。不把一个品牌永久等同一种风格。每类初期只有一个或少量来源，不足以覆盖该类全部变化。

## 二、独立属性标签

| 轴 | 可选值 / 说明 |
|---|---|
| 明暗主题 | light / dark / dual；优先问用户与使用环境 |
| 信息密度 | sparse / balanced / dense；与功能所需内容独立核对 |
| 布局 | centered / grid / asymmetric / modular |
| 字体气质 | sans / serif / mono / mixed；实际中文适配另验 |
| 色彩 | neutral / warm / cool / vivid；描述颜色关系而非只抄色号 |
| 形状与材质 | sharp / rounded；flat / grain / glass / depth |
| 图像策略 | product / photography / illustration / data / type-led |
| 动效 | static / subtle / expressive / unknown；静态截图默认 unknown |

## 三、使用情境与约束

情境标签：`workbench`、`service`、`product`、`editorial`、`portfolio`、`campaign`。另记媒介、视口、语言、用户任务、内容规模、无障碍要求。获奖营销站不能直接证明适合密集专业工具。

## 四、把术语解释成选择

给用户的方向卡只保留：一张图、一句气质、两个可见特征、一个取舍。例：A“信息清楚、操作集中”，B“图片更有存在感、浏览节奏更舒展”。先保证内容与目标可比，再问用户喜欢哪部分；允许选 A 的布局 + B 的字体，不要求整套照选。

新增分类需至少两张有不同观察价值的精选图片、明确区别和适用范围；只有一个流行标签时先加属性标签，不建立空目录。未来可以按真实任务增加温暖有机、瑞士网格、复古、实验排版等细分，不预建空图库。
