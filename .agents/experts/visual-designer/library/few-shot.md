# 视觉 few-shot：用样例训练当前判断

这是一种提示与参考使用方法，不是对模型做参数训练。实际打开图片，再阅读解释；每次通常只选 2–4 张相关图。

## 单个示例卡

`任务约束 → 图中事实 → 设计决策 → 当前任务迁移 → 不迁移的部分`。

- **任务约束**：受众、核心行为、内容量与输出媒介。
- **图中事实**：列 2–3 个能指到画面位置的事实，避免“高级/漂亮”空标签。
- **设计决策**：这些比例、对齐、字重或色彩关系如何服务任务？
- **迁移**：落到本任务具体的布局、层级或组件规则。
- **不迁移**：品牌、照片、文案、无关动效以及不适用的功能取舍。

## 示例一：复杂工作台不照搬营销首屏

输入：需要保留镜片列表、属性表和主视图，长时间操作；用户想要克制。

参考：[功能理性目录图](styles/functional/02-directory.png)与[克制极简亮色图](styles/minimal/02-light.png)。观察目录图的左侧稳定文本锚点、分组行距和右侧辅助列；极简图把一个对象设为主重心。迁移为主视图占主要面积，属性字段统一对齐、靠分组而非装饰分隔，主动作只用一种强调色。不把营销图的大留白照搬成空荡工作台，也不删属性来模仿简洁。此为方法示例，并非当前用户的已确认风格。

## 示例二：文化专题先建立阅读节奏

输入：介绍一个主题并引导读者继续阅读，而非立即购买。

参考：[编辑封面](styles/editorial/01-cover.png)和[图文场景](styles/editorial/02-story.png)。观察封面的衬线标题与居中留白、场景图中的大面积摄影与边角信息。迁移为标题—主图—导语—正文的节奏；文字叠图时另验实际对比，不直接复制样例中较弱的白字对比。保留用户中文内容，不复制照片与品牌。

## 示例三：品牌表达可以有两种不同路径

输入：创意作品集，需要有个性，同时能迅速看懂做什么。

参考：[色彩型表达](styles/expressive/01-color.png)和[字体型表达](styles/expressive/02-type.png)。前者以色彩流向和首屏文案组织注意力，后者以紧凑大字与非对称网格表达个性。给用户看 A“色彩流动、明亮”，B“字形强烈、暗色”，解释差别后再按其选择做新设计。不能把 A/B 限制为换背景色，也不能从截图推断整站交互质量。

## 防止示例固化

样例不合当前内容密度、媒介或目的时弃用。可以补一个跨风格对照，检查自己是不是只会套模板。复评以本次 brief 与真实渲染为准，图片相似度不是质量指标。用户的 A/B 选择只记录为本任务决定；若要长期沿用，另问是否作为该场景偏好保存。

## 从参考到小样

参考图片选完后，仅用当前任务同一小段真实内容制作 A/B 风格预览，例如报告的一段结论和一组数据。用户先选方向，再制作完整报告。不要把完整页面和所有子页面都实现后才拿来问“喜欢哪版”；也不为两个未选样式做全套交互和响应式验收。
