# Anthropic · 温暖的编辑式科技表达

分析命名：**纸面暖中性色 + 理性无衬线 + 人文衬线 + 宽松编辑网格**。基于 [Anthropic 首页](https://www.anthropic.com/) 本次实际画面，不把 Claude 产品 UI 或历史官网混为同一对象。

2026-09-26，1280×900，检查首屏与发布卡片区。当前官网不是“全站衬线”：首屏主标题是粗无衬线，右侧说明和发布正文使用衬线，导航与元信息另成层级。

| 维度 | 画面依据 | 可迁移原则 |
|---|---|---|
| 色彩 | 暖纸白底、近黑文字、米灰卡片；主要按钮近黑 | 低刺激的阅读环境与明确文字对比；不要把所有文本都降成低对比灰 |
| 排版 | 左侧大无衬线宣言，右侧较小衬线说明 | 用两种字体角色区分“立场/导航”和“解释/阅读”，不只是混搭字体装饰 |
| 网格 | 首屏左右两栏；下方三张等宽发布卡片 | 稳定对齐、大块空间与内容组织共同建立可信感 |
| 层级 | 大标题、短说明、主视觉、发布列表、元信息逐级展开 | 让读者先理解定位，再选择深入材料，不让所有模块同样抢眼 |
| 图形 | 当前发布主视觉是大幅渐变/影像，正文卡片相对平静 | 只在关键叙事区设置视觉高潮，不把整页做成持续炫技 |
| 细节 | 卡片有圆角，字段之间用很淡的细线；日期/类别标签近等宽气质 | 表面温和、结构清楚；圆角与细线服务分组，不必扩散到所有物件 |

实测 body 背景 `rgb(250,249,245)`（#FAF9F5），首屏主标题 `rgb(20,20,19)`（#141413），计算字体 `Anthropic Sans, Arial, sans-serif`，本视口约 57.73px。其余颜色/字体描述为视觉观察，未给出未经测量的精确数值。英文字体组合应在中文场景重新选型和检查。

few-shot：任务“可信、可读、有人文气质的技术介绍” → 观察“暖纸白+字体角色分工+稳固网格” → 迁移为中文标题/正文分工、有限黑色动作、稳定阅读宽度。不要把营销页的大留白搬进高频操作工具，也不复制品牌字体、图像与文案。

与 Heron 对照：两者都有克制色彩和清楚秩序；Heron 用图纸刻度、线框和领域图像强化工程性，Anthropic 用字体对话和阅读节奏强化人文与机构可信感。这里是设计分析，不等同用户已确认喜欢这些具体因素。
