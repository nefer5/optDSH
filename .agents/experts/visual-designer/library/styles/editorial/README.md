# 编辑叙事

以字体气质、图像和阅读节奏组织内容。本组两张来自同一出版品牌。

| 图片 | 来源与状态 | 借鉴 | 不照搬 |
|---|---|---|---|
| [01-cover.png](01-cover.png) | [Kinfolk](https://www.kinfolk.com/) 首页顶部；2026-09-26，1280×900 | 衬线标题、居中封面、留白形成阅读仪式感 | 封面作品和品牌；极低密度不是所有内容的正确选择 |
| [02-story.png](02-story.png) | 同页，scrollY=900；同日期/视口 | 大幅摄影与边角文字形成场景叙事 | 白字叠浅图有对比风险；底部订阅条和右侧浏览器浮层不是风格目标 |

标签：editorial、photography、serif、light、sparse；动效未评估。few-shot 迁移：由标题和图片决定节奏，再安排正文；文字叠图必须按实际背景重新测可读性。

另一个不同方向是 [Anthropic：人文科技的编辑式表达](anthropic.md)，附首屏和卡片区两张图。阅读叙事不一定以摄影和衬线标题为中心，也可以通过无衬线标题与衬线正文的角色分工实现。
