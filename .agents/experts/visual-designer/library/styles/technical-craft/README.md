# 工程手作感 · Heron AI

分析命名：**工程制图秩序 + 纸面质感 + 编辑式大标题**。这是对实际画面的归纳，不是网站官方风格名称。

来源：[用户指定的 CSSDA 条目](https://www.cssdesignawards.com/sites/heron-ai/50037/)，[Heron AI 原站](https://heronaiapp.com/)。页面署名 Bearplus。2026-09-26 在 1280×900 视口检查首屏与问题模块；仅有限滚动观察，不是完整交互验收。

| 维度 | 可见选择 | 作用与迁移方式 |
|---|---|---|
| 版式 | 细边框把页面划成图纸一样的格子，角标、刻度、编号构成辅助秩序 | 为技术产品提供明确的专业语境；工作台可借鉴区域对齐和编号，不必到处加装饰刻度 |
| 配色 | 米白纸面、炭黑主体、浅灰结构线，极少量橙红标记和动作 | 大面积克制，小面积建立注意力；强调色承担状态或动作，避免所有元素都橙红 |
| 字体 | 大写、紧凑无衬线标题；细小等宽风格导航、编号和标注 | 主标题表达力度，技术注释表达精密；中文不能机械照搬英文紧字距与小字号 |
| 图像 | 黑白建筑、剖面感、颗粒与线描，和产品领域直接关联 | 用领域自己的视觉素材建立个性；光学场景可用光路、透镜剖面或仪器图，而不是借用建筑图 |
| 空间 | 超大主图配局部密集信息，留白和细网格共存 | 叙事首屏与信息模块切换，设计感来自比例控制而非堆组件 |
| 动态 | 看到了启动阶段与滚动时的画面变化 | 可研究其节奏；未确认完整键盘、滚动和移动端行为，不照搬强制开场等待 |

few-shot：任务“技术感、精密、又不冰冷” → 观察“纸面+网格+领域图像” → 迁移“暖中性色、统一细分隔、科学示意图、有限强调色”。不要照搬低对比注释、模糊小字、加载等待、图像和品牌标志。

适用：工程产品介绍、技术作品集、科研专题、专业工作台的视觉主题。专业工作台应比营销页提高文字对比与实际信息密度。标签：light、warm-neutral、grid、sharp、grain、technical、mixed-type。
