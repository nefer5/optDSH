# 视觉设计专家 · 0.7.0

一个可复用的视觉设计、实现与评估专家。它把目的、受众和参考转成可查看的设计；支持网页/专业工作台、研究报告、PPT等媒介。自查不等同独立验收。

## 源与维护

本目录是唯一源：agent.json定义身份与版本，instructions.md定义行为，library保存分类/参考及来源，resources.json定义本机分发白名单。按“简短确认 → 低成本小样（需要时）→ 用户选择 → 一套完整实施 → 实际画面检查”执行。只评估不自动改作品。

| 任务 | 建议输入 | 交付 |
|---|---|---|
| 创作/改版 | 用途、受众、必须保留内容、参考、输出位置 | 可查看作品与关键取舍、验证范围 |
| 只读评估 | 真实页面或截图、评价目标、偏好 | 具体位置、证据、影响、改法 |
| A/B比较 | 同内容同范围、差异目标 | 两份小样，等待选择后深化 |
| 公司PPT | 模板、汇报目的、听众、内容材料 | 内容优先，走对应PPT技能，不默认A/B |

参考入口：[START](library/START.md)、[分类](library/taxonomy.md)、[使用示例](library/few-shot.md)、[产品UI专题](library/collections/product-ui/README.md)。每次只加载相关1–2类及少量图；需要图片能力，不能以读过文件路径冒充看过画面。

## 个性化与产品规则

[偏好模板](preferences.example.md)可公开。preferences.md与private/是本机个人记录，不公开分发；用户可在多个本机项目间显式链接共享。本次任务与目标项目规则优先，光学约束仅在光学任务中使用。

## 分发与验证

仓库的expert-distribute适配Codex、OpenCode、Claude Code、DSH。主Agent调用时传入产品根、任务范围、已确认偏好和允许输出。DSH单task委派保持原生Subagent循环；新模型/图像端点需独立验证。

版本更新后先分发再检查；文件哈希一致、宿主加载与真实设计表现分开报告。详见[发布边界](PUBLICATION.md)。本次0.7.0统一权威源与偏好，未宣称重新完成模型行为评测。
